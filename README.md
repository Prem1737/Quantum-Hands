# Quantum Hands V5

A futuristic hand-tracking web application built using MediaPipe Hands and JavaScript.

## Features

- Real-time hand tracking
- Cyberpunk neon hand skeleton
- Fingertip glow effects
- Energy trails
- Pinch lightning
- Wrist holographic rings

## Technologies

- HTML5
- CSS3
- JavaScript
- MediaPipe Hands

## How to Run

1. Open the HTML file in a browser.
2. Click Activate.
3. Allow camera access.
4. Move your hands in front of the camera.
